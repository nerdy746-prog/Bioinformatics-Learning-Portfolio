# BLASTN Analysis of the Human PAH Gene

## Objective
To perform nucleotide BLAST (BLASTN) analysis of the human phenylalanine hydroxylase (PAH) gene.

## Database
NCBI Nucleotide Collection (nr/nt)

## Reference sequence
NM_000277.3

## Results
- Human PAH transcript variant 1: 100% query cover, 100% identity.
- Human PAH transcript variant 2: 100% query cover, 100% identity.
- Macaca mulatta PAH: 100% query cover, 95.12% identity.
- Papio anubis PAH: 100% query cover, 95.09% identity.

## Conclusion
BLASTN identified highly similar PAH nucleotide sequences in humans and other primates. The results demonstrate sequence similarity across these organisms.
